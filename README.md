# usage-meter-plus

Claude Code の入力欄の上に、**週間・5時間の使用量**と、**このセッションでどれだけ使ったか**を常に表示する Mod（プラグイン）です。

```
週間  ████████░░░░  41%  経過 56%  リセットまで 3日10時間   文脈 34%   今回 +1.2%
5時間 ██████░░░░░░  83%  経過 40%  リセットまで 3時間0分   今回 +12.5%   累計 約386円（158円/ドル）
```

- **バーと%**：使用率。70%未満は緑、70%以上は黄、90%以上は赤。
- **経過**：リセット周期のうち、時間がどこまで進んだか。使用率がこれより小さければ余裕あり。
- **今回**：このセッションを開いてから、その段の使用率（週間／5時間）が何ポイント増えたか。
- **累計 約◯円**：このセッション全体の消費を API 定価で円に換算した目安（実際の請求額ではなく、プランによっても変わりません）。括弧内は使った為替レートで、1日1回自動取得します。取得できなかったときは「150円/ドル・仮」と出ます。

## 入れ方

Claude Code に次の文をそのまま送ってください。

> `kikutani44-hash/claude-code-usage-meter-plus` をマーケットプレイスに追加して、`usage-meter-plus` をユーザー用プラグインとしてインストールして。

終わったら**新しいセッションを開く**と表示されます。

## 外し方

Claude Code に次の文をそのまま送ってください。

> `usage-meter-plus` プラグインをアンインストールして、`usage-meter-plus-market` マーケットプレイスも削除して。

## 注意

- 使用率が出るのは Claude の Pro/Max プランでログインしている場合です。それ以外や最初の応答前は「取得待ち」と表示されます。
- 使用率はアカウント全体の値なので、同時に動かしている別セッションの分も「今回」に混ざります。
- 為替レートの取得のため、1日1回 `open.er-api.com` に通信します（AI のトークンは使いません）。
